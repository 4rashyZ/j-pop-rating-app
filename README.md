# OTO — J-Pop Rating Prototype

A small, browser-only J-Pop discovery and rating prototype built with Next.js and TypeScript.

## Phase 1 features

- Browse six sample artists
- Search and filter artists by genre
- View artist portfolios and sample popularity statistics
- Rate individual songs from 1–10
- Save favourite artists
- Keep ratings and favourites in browser `localStorage`
- Responsive desktop and mobile layouts

The popularity values are demonstration data and are not connected to YouTube or Spotify APIs.

## Run locally

Install Node.js 20.9 or newer, then run:

```powershell
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Validation

```powershell
npm run lint
npm run build
```
